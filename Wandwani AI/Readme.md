# PathSync AI 🚀

PathSync AI is an AI-powered career guidance and education-to-employment platform designed to help students navigate career pathways, identify skill gaps, and receive personalized learning guidance.

Built for the Higher Education & Skilling track, the platform focuses on improving employability, career awareness, and student readiness through an intelligent mentorship experience.

---

## 🌟 Features

### 🤖 AI Career Mentor
Interactive chatbot that guides students with:
- Career suggestions
- Learning roadmaps
- Interview preparation
- Skill recommendations
- Project ideas

### 📊 Skill Gap Analyzer
Students can:
- Select target careers
- Compare current skills with industry-required skills
- Identify missing skills
- Get learning recommendations

### 🛣 Career Roadmaps
Provides structured pathways for careers like:
- AI Engineer
- Frontend Developer
- Backend Developer
- Full Stack Developer
- Data Scientist
- Cybersecurity Analyst

### 🔥 Personalized Dashboard
Tracks:
- Skills progress
- Profile score
- Learning streak
- Career goals

### ☁ Firebase Integration
Uses Firebase for:
- Authentication
- Firestore database
- User data storage

## 🤖 AI Implementation

Initially, the project was designed to integrate real-time AI APIs using external LLM services.

The system was tested with:
- Google Gemini API
- Hugging Face Inference API

However, due to API quota limitations and free-tier restrictions during development, the final implementation uses a lightweight rule-based AI chatbot system.

The chatbot still provides:
- Context-aware responses
- Career guidance
- Roadmap recommendations
- Skill suggestions
- Interview tips

This approach also improves:
- Offline readiness
- Low-connectivity usability
- Faster response time
- Reliability during demos

## 🎯 Problem Statement

Students often face fragmented education-to-employment journeys with limited access to:
- Career guidance
- Skill mapping
- Industry awareness
- Personalized mentorship

PathSync AI aims to bridge this gap using intelligent digital guidance tools.
